# 网页对齐这一路：**实测台账**

> 与 `plan/measurements.md` 分工：那一份量的是**性能**（吞吐/并发/IO），
> 这一份量的是**正确性**（引擎某个算子在给定输入下到底给出什么数）。
> 混在一起会让"这个数是性能还是正确性"变得看不清 —— 两份文件各自成立。

**谁在引用这一份**（第 69 轮补）：`web/capabilities.json` 里带数的那些条目 ——
`blend-mode` / `filter.hue-rotate` / `filter.brightness` / `filter.saturation` / `filter.drop-shadow` /
`geometry.corner-radius` / `geometry.clip-path` / `geometry.clip-path-polygon` / `geometry.mask` / `backdrop-filter` ——
每条都有一句指向这里。**没在里面点名的 GPU 用例也照跑照守**（其中不少是"拒绝路径"的行为判据），
只是它们守的条目没逐条引用它们（第 69 轮查过：29 条里 17 条属这种）。

**规矩（与差异台账同理）**：量过的写数 + 判据 + 哪一轮；**没量过的不许写数**，
写明为什么没量（多数是"要浏览器"）。

**机器口径（务必带上，否则数字会飘）**：以下全部来自**同一次会话、同一台机器**：

    GPU：NVIDIA GeForce RTX 4070（vendor 4318 / device 10118），driver 610.74，backend **Vulkan**
    跑法：cargo test -p dhampir-worker --test timeline -- --ignored（native 后端经 open_leg）
    系统：Windows

（第 57 轮起，实测用例自己会把适配器打出来 —— 数字与机器一起留在日志里。换机器重跑时请更新这一行。）

量法的**诚实前提**（写在手册里也写在这里）：DOM 宿主画的是**占位方块**（它不解码素材），
量测页（`web/dom-measure.html`）把那块方块涂成与引擎**同色同尺寸** ——
量的是"**浏览器对同一几何 / 同一混合 / 同一掩码的处理**"，不是"宿主默认外观像不像引擎"。

**浏览器 WebGPU 那一腿（不是 CSS，是同一段 WGSL）：预览链路 vs 成片**（第 83 轮，G2）

| 量的是什么 | 实测 | 判据（会红的那个） | 轮次 |
|---|---|---|---|
| `engine.seek → dhampir_project_draw → canvas` vs CLI `dhampir frame` | 工程 `out/effects-demo`（4 轨 / 103 层 / 860 帧，覆盖 16 条效果 + 9 条混合 + 5 种裁剪 + 圆角/素材掩码/渐变掩码/投影/背景滤镜/8 种缓动），帧 0/200/400、640×360：**max|Δ| = 1**、最差帧 SSIM **0.999903442**、PSNR **62.44 dB** | `node scripts/check-preview-path.mjs`（档位 `scripts/framediff-thresholds.toml` 的 default：1 LSB） | 83 |

这条与上面那三条**性质不同**：上面是"引擎 vs 浏览器自己的 CSS 合成器"（算法不同，差异按**量到的数**定档）；
这一条是"同一段 WGSL、两套编译器与驱动"（差异性质是**舍入**）⇒ 它吃的是跨厂商那一档（1 LSB），
而量到的读数**正好就在那一档上** —— 没有任何放宽。
